QUEUE (Linked List Implementation)

This folder contains Queue implementations using Linked List and best practice examples.

Contents:
1. QueueLinkedList.java - Basic FIFO queue using linked list
2. CircularQueueLinkedList.java - Circular queue implementation
3. DequeLinkedList.java - Double ended queue
4. PriorityQueueLinkedList.java - Priority queue (linked list based)
5. QueueBestPractices.txt - Theory notes

NOTE: No 'src' folder structure used.
